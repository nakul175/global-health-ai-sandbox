- [Baseline archive](pre-v1.1/baseline-documentation.zip): 137 available earlier text documentation, specification, contract, fixture, catalogue and verification files, preserving their repository-relative paths and exact bytes.

## Missing original artifacts

The repository does not contain the original Global_Health_AI_Sandbox_BRD.docx or Global_Health_AI_Sandbox_FSD.docx, nor every original standalone HLD/LLD/wireframe document or earlier conversation attachment. The available traceability model preserves all 456 requirement records, 35 functional modules, 113 target screens and 40 critical scenarios. The implementation pack retains ten engineering specifications and the full structured test catalogue.

The new BRD/FSD Markdown reading editions reconstruct those detailed records and label their provenance. They are not falsely presented as the missing originals. If original files are recovered later, preserve them in a new provenance-documented historical directory; do not replace this archive or discard current work.
